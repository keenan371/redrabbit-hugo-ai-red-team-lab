# Upwork Portfolio Description

Built a local AI-security red-team demonstration that tests a defensive watchdog against a fixed catalog of safe prompt-injection, mock system-identifier, mock data-leakage, and authority-escalation simulations.

The project uses repeatable test cases, structured JSONL event logging, baseline-versus-hardened comparison, automated verification, and a localhost-only control interface. In the completed hardened run, Hugo classified and refused 4 of 4 simulated unsafe requests without exposing protected mock values.

All attacks in this project are authorized, fictional, local-only simulations. No public systems, client data, credentials, production environments, or third-party targets were accessed.
